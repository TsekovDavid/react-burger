# Stellar Burgers

Учебный проект Yandex Practicum: интерактивная космическая бургерная на React и TypeScript.

## Деплой

Актуальная версия опубликована по адресу: [http://89.169.167.127](http://89.169.167.127)

## Функциональность

- загрузка ингредиентов из API;
- сборка бургера с помощью Drag and Drop;
- изменение порядка и удаление ингредиентов;
- расчёт количества ингредиентов и итоговой стоимости;
- создание заказа;
- регистрация, авторизация и восстановление пароля;
- защищённый личный кабинет и редактирование профиля;
- публичная лента заказов и история пользователя через WebSocket;
- модальные и отдельные страницы ингредиентов и заказов;
- обновление access token и повтор защищённых запросов.

## Технологии

- React 19;
- TypeScript;
- Vite;
- Redux Toolkit и React Redux;
- React Router;
- React DnD;
- CSS Modules;
- Vitest;
- Playwright и HAR-моки;
- ESLint, Stylelint и Prettier.

## Запуск проекта

Для работы требуется Node.js 20 или новее.

```bash
npm ci
npm run dev
```

После запуска приложение будет доступно по адресу `http://localhost:5173`.

## Production-сборка

```bash
npm run build
npm run preview
```

## Проверки

```bash
# Модульные тесты Redux-слайсов
npm test -- --run

# Сквозной тест конструктора
npm run e2e -- --project=chromium

# Линтеры и форматирование
npm run lint

# Проверка TypeScript
npx tsc -b --pretty false

# Production-сборка
npm run build
```

Playwright-тест проверяет открытие модального окна ингредиента, добавление ингредиентов в конструктор через Drag and Drop и создание заказа. Используемые API-запросы замокированы HAR-файлами.

## Структура

```text
src/
├── assets/       # изображения проекта
├── components/   # переиспользуемые компоненты
├── hooks/        # пользовательские React-хуки
├── pages/        # страницы приложения
├── services/     # Redux-слайсы, экшены и middleware
└── utils/        # API, типы и вспомогательные функции

e2e/              # Playwright-тест и HAR-моки
```
